NETSERA SITE REPAIR V5

This is the "put the whole site back together" patch.

What was broken:
- globals.css had been replaced by a hero-only stylesheet
- SiteHeader classes therefore had no styles
- PublicServicesSection and PublicProjectsSection also lost their card/grid styling
- the page looked like raw HTML below the hero

What this patch restores:
- coherent SiteHeader styling
- full service module cards
- project engineering case cards
- complexity-to-clarity diagram
- workflow section
- infrastructure dashboard
- contact console
- footer
- responsive behavior
- the latest user video: netsera-binary-flow-v5.webm

No backend/API/admin logic is changed.

Apply:
1. Extract ZIP into the ROOT `netsera-website`.
2. Replace matching frontend files.
3. Keep your existing ContactForm.tsx; this patch does not replace it.
4. Run:
   cd frontend
   npm run typecheck
   npm run build
   npm run dev
5. Open http://localhost:3000
6. Do NOT push until you visually approve it.

Expected:
- header should again be a proper sticky dark/glass header
- CORE MODULES should be a 3-column card grid on desktop, not raw text
- Projects should be styled cards
- hero should be balanced 42/58 with v5 WebM
