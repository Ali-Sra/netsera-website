# Netsera Website

Production-oriented full-stack website foundation for Netsera.

## Stack
- Next.js + React + TypeScript + Tailwind CSS
- ASP.NET Core Web API + C#
- PostgreSQL
- Docker + Docker Compose
- GitHub Actions

## Project structure
- `frontend/` Next.js application
- `backend/` ASP.NET Core API
- `docs/` architecture and project documentation
- `infrastructure/` reverse proxy, deployment, backup and monitoring assets

## Development approach
The project is built incrementally. Phase 1 establishes the repository foundation, local development structure, environment configuration, and documentation before feature development.
