# Netsera Frontend

Next.js + React + TypeScript + Tailwind CSS frontend for Netsera.

## Requirements
- Node.js 20.9+
- npm

## Run locally
```powershell
cd frontend
npm install
npm run dev
```
Open http://localhost:3000

## Validate
```powershell
npm run typecheck
npm run build
```

## Phase 2 scope
- responsive commercial landing page
- reusable header/footer components
- SEO metadata
- loading and 404 states
- accessible mobile navigation
- Tailwind CSS design system foundation

The contact form is intentionally disabled until the backend API is implemented.
