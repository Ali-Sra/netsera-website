PHASE 5 APPLY — ADMIN AUTH + DASHBOARD

1. Merge this package into the existing netsera-website root.

2. IMPORTANT: Phase 4 should already be merged locally.

3. Create migration:
   cd backend

   dotnet ef migrations add AddAdminAuth `
     --project .\src\Netsera.Infrastructure `
     --startup-project .\src\Netsera.Api `
     --output-dir Persistence\Migrations

   dotnet ef database update `
     --project .\src\Netsera.Infrastructure `
     --startup-project .\src\Netsera.Api

4. Configure LOCAL bootstrap credentials for this terminal:
   $env:ASPNETCORE_ENVIRONMENT="Development"
   $env:AdminBootstrap__Email="YOUR_EMAIL"
   $env:AdminBootstrap__Password="YOUR_UNIQUE_PASSWORD_AT_LEAST_12_CHARS"

   DO NOT paste your real password into ChatGPT or commit it to Git.

5. Validate backend:
   dotnet build
   dotnet run --project .\src\Netsera.Api

6. New terminal:
   cd frontend
   npm run typecheck
   npm run build
   npm run dev

7. Open:
   http://localhost:3000/admin/login

8. Login with the bootstrap credentials.

9. Verify the Phase 4 contact message appears.

10. Test New / Read / Archived status changes.

11. Only after all tests pass:
    git add .
    git commit -m "feat: add secure admin authentication and message dashboard"
    git push
