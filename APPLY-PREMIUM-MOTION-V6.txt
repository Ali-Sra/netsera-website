NETSERA PREMIUM MOTION V6

This patch upgrades the current Netsera public website without changing backend, API, admin, or authentication.

WHAT CHANGES
- keeps the current v5 hero WebM
- scroll-reveal motion via IntersectionObserver
- subtle mouse-follow ambient light on desktop
- top scroll-progress line
- cinematic header and hero depth
- animated grid and video sheen
- service cards with scan/terminal motion
- animated topology paths in project cards
- interactive workflow nodes
- live-feeling infrastructure dashboard
- animated complexity diagram
- animated contact request pipeline
- stronger section rhythm and spacing
- reduced-motion accessibility support
- no new npm dependency

APPLY LOCALLY
1. Extract this ZIP into the ROOT netsera-website folder.
2. Replace matching files.
3. Stop the running dev server with Ctrl+C.
4. From frontend run:

Remove-Item -Recurse -Force .next
npm run typecheck
npm run build
npm run dev

5. Hard refresh Chrome with Ctrl+Shift+R.
6. Review desktop and mobile.
7. Do NOT push to GitHub until visually approved.

No backend or database files are included.
