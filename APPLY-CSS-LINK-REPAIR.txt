NETSERA CSS LINK REPAIR

Problem:
Hero module CSS can load independently while the rest of the website looks like raw HTML.
That happens when app/layout.tsx does not import ./globals.css, or Next dev cache still serves the broken layout.

This patch restores:
import "./globals.css";

Apply to ROOT netsera-website and replace:
frontend/src/app/layout.tsx

Then from frontend:
1. Stop npm run dev (Ctrl+C)
2. Remove-Item -Recurse -Force .next
3. npm run typecheck
4. npm run build
5. npm run dev
6. Hard refresh browser: Ctrl+Shift+R
