PHASE 9 APPLY — CI/CD + PRODUCTION DOCKER + NGINX

1. Merge this ZIP into the existing netsera-website root.
   Phase 8 should already be present locally.

2. No EF migration is required.

3. Validate normal source builds first:

   cd backend
   dotnet restore
   dotnet build
   dotnet test
   cd ..

   cd frontend
   npm ci
   npm run typecheck
   npm run build
   cd ..

4. Prepare production-like environment:

   Copy-Item .env.production.example .env.production

   IMPORTANT:
   Edit .env.production and replace BOTH placeholder passwords.
   Do not commit .env.production.

5. Build production containers:

   docker compose --env-file .env.production -f docker-compose.prod.yml build

6. Start:

   docker compose --env-file .env.production -f docker-compose.prod.yml up -d

7. Check:

   docker compose --env-file .env.production -f docker-compose.prod.yml ps

8. Open:

   http://localhost:8088
   http://localhost:8088/health
   http://localhost:8088/health/ready
   http://localhost:8088/admin/login

9. Stop production-like stack when finished:

   docker compose --env-file .env.production -f docker-compose.prod.yml down

10. Before Git commit, verify .env.production is NOT staged:

   git status

11. Commit only after source and Docker tests pass:

   git add .
   git status
   git commit -m "ci: add production containers and continuous integration"
   git push

12. After push, open GitHub -> Actions and confirm CI is green.
