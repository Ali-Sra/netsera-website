Merge this package into the existing netsera-website repository root.

Then validate:

1) Remove generated TS build cache from Git tracking if present:
   git rm --cached frontend/tsconfig.tsbuildinfo

2) Backend build:
   cd backend
   dotnet restore
   dotnet build

3) Database with Docker:
   cd ..
   docker compose up -d postgres

4) Create EF migration (after installing dotnet-ef if needed):
   cd backend
   dotnet ef migrations add InitialCreate --project src/Netsera.Infrastructure --startup-project src/Netsera.Api --output-dir Persistence/Migrations
   dotnet ef database update --project src/Netsera.Infrastructure --startup-project src/Netsera.Api

5) Run API:
   dotnet run --project src/Netsera.Api

Then test:
   http://localhost:<shown-port>/swagger
   http://localhost:<shown-port>/health
