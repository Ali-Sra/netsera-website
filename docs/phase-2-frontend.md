# Phase 2 — Frontend Foundation

## Goal
Deliver the first production-oriented Netsera user interface with a clear design language and a maintainable Next.js structure.

## Implemented
- Next.js App Router
- TypeScript strict mode
- Tailwind CSS 4.x
- responsive navigation
- hero and infrastructure overview
- services section
- working-method section
- project showcase
- contact placeholder
- footer
- metadata, Open Graph baseline, robots policy
- loading and not-found states
- reduced-motion accessibility support

## Intentionally deferred
- backend API
- live contact form
- admin panel
- authentication
- database
- CMS/content editing
- analytics
- CI/CD

## Next phase
ASP.NET Core API + PostgreSQL integration and a working contact-message flow.
