PHASE 4 APPLY

Merge this package into the root of your existing netsera-website repository.

Then:

1. PostgreSQL
   docker compose up -d postgres

2. Backend
   cd backend
   $env:ASPNETCORE_ENVIRONMENT="Development"
   dotnet run --project .\src\Netsera.Api

3. In a NEW terminal:
   cd frontend
   Copy-Item .env.example .env.local
   npm run typecheck
   npm run build
   npm run dev

4. Open:
   http://localhost:3000

5. Submit the contact form.

6. If successful, commit:
   git add .
   git commit -m "feat: connect contact form to Netsera API"
   git push
